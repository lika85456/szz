
# W-1-1
## front
Co je Apache Spark a jaké jsou jeho hlavní výhody oproti Hadoop MapReduce?
## back
- Apache Spark je open-source výpočetní framework pro distribuované zpracování dat.
- Hlavní výhody oproti MapReduce (Hadoop):
  - Rychlost díky in-memory zpracování dat.
  - Jednoduché API pro práci s daty.
  - Výrazně nižší latence oproti diskově orientovanému MapReduce.

# W-1-2
## front
Popiš architekturu Apache Spark (roli hlavních komponent).
## back
- Apache Spark využívá Master-Worker architekturu:
  - **Driver Program** – řídí aplikaci, plánuje úlohy, spravuje metadata.
  - **Cluster Manager** (např. YARN, Mesos, Kubernetes) – přiděluje prostředky.
  - **Executors** – logické instance na workerech, vykonávají úlohy a zpracovávají data.

# W-1-3
## front
Co je RDD (Resilient Distributed Dataset) ve Sparku a jaké jsou jeho vlastnosti?
## back
- RDD (Resilient Distributed Dataset) je základní datová abstrakce ve Sparku.
  - Imutabilní (neměnné).
  - Paralelně distribuované mezi uzly clusteru.
  - Odolné vůči chybám díky **lineage** (zachování historie operací).

# W-1-4
## front
Jaký je rozdíl mezi transformacemi a akcemi v Apache Spark?
## back
- **Transformace** (např. $map$, $filter$):
  - Vytváří nové RDD z existujícího.
  - Jsou **lazy** (nevykonávají se ihned, ale až při akci).
- **Akce** (např. $collect$, $count$):
  - Spouští skutečný výpočet a vrací výsledek.

# W-1-5
## front
Jak funguje DAG (Directed Acyclic Graph) v Apache Spark?
## back
- Výpočetní úloha ve Sparku je interně reprezentována jako DAG (aciklický orientovaný graf):
  - Uzly reprezentují RDD.
  - Hrany tvoří transformace mezi nimi.
  - DAG je optimalizován a rozdělen na etapy (stages), které jsou následně zpracovány.

# W-1-6
## front
Co znamená "shuffle operace" ve Sparku a proč jsou náročné?
## back
- Shuffle operace nastávají při převodu/přeskupení dat mezi uzly (např. $groupByKey$, $reduceByKey$).
- Vyžaduje přenos dat mezi více uzly – časově a výpočetně náročné.

# W-1-7
## front
Jakým způsobem je Spark odolný vůči chybám?
## back
- Spark používá k obnově dat **lineage** – sled operací vedoucích k aktuálnímu RDD.
- Nepoužívá tradiční replikaci dat jako Hadoop, ale obnovuje ztracená data znovuvýpočtem podle historie transformací.

# W-1-8
## front
Napiš příklad jednoduchého Spark programu v Scala pro výpočet součtu všech prvků seznamu po vynásobení dvěma.

# W-2-1
## front
Co je Elasticsearch a jaký problém řeší?
## back
- Elasticsearch je vyhledávací engine postavený nad Lucene.
- Slouží pro rychlé a distribuované indexování i vyhledávání dokumentů (např. logy, fulltext).

# W-2-2
## front
Vysvětli základní pojmy v Elasticsearch (Cluster, Node, Index, Document, Shard, Replica).
## back
- **Cluster** – skupina uzlů pracujících společně.
- **Node** – jeden server v clusteru.
- **Index** – kolekce dokumentů, obdobné jako databáze.
- **Document** – základní jednotka dat ve formátu JSON.
- **Shard** – část indexu, umožňuje paralelizaci a škálování.
- **Replica** – kopie shardu, zvyšuje dostupnost a výkon.

# W-2-3
## front
Co je inverzní index v Elasticsearch a proč je důležitý?
## back
- Inverzní index je základní datová struktura pro textové vyhledávání:
  - Místo aby uchovával všechny dokumenty, uchovává mapování termín → seznam dokumentů, kde se termín vyskytuje.
  - Umožňuje velmi rychlé vyhledávání dokumentů obsahujících konkrétní slovo.

# W-2-4
## front
Jak probíhá distribuované indexování v Elasticsearch?
## back
- Při vložení dokumentu:
  - Pomocí hash funkce se určí primární shard, kam dokument patří.
  - Dokument je indexován na konkrétním uzlu.
  - Data jsou replikována na základě nastavení počtu replik (např. 1 replika znamená dvě kopie dokumentu).

# W-2-5
## front
K čemu slouží Query DSL v Elasticsearch? Uveď příklad jednodušeho dotazu.
## back
- Query DSL je flexibilní dotazovací jazyk v JSON formátu pro hledání a agregace dat v Elasticsearch.
- Příklad dotazu:
```
GET /index/_search
{
  "query": {
    "match": {
      "title": "Distribuované systémy"
    }
  }
}
```

# W-2-6
## front
Jak funguje vyhledávání ve více šardech v Elasticsearch?
## back
- Dotaz je paralelně poslán na všechny primární a replikované shardy.
- Výsledky z jednotlivých shardů jsou agregovány a seřazeny podle relevance.

# W-3-1
## front
Jaké základní principy distribuovaných systémů využívají Spark i Elasticsearch?
## back
- Oba systémy (Spark i Elasticsearch):
  - Využívají **shardování** (rozdělení dat do částí).
  - Umožňují paralelní zpracování dat na více uzlech.
  - Implementují **odolnost vůči chybám** a replikaci/lineage.
  - Jsou škálovatelné horizontálně.

# W-3-2
## front
Vyjmenuj hlavní rozdíly v zaměření Spark a Elasticsearch.
## back
- Spark – primárně určen pro distribuované **výpočty** a analýzu dat.
- Elasticsearch – určen pro **indexaci** a rychlé vyhledávání v datech (fulltext, logy).
- Oba využívají sharding a paralelismus, ale řeší jiné typy úloh.
