
# SP-29-1
## front
Co zkoumá architektura číslicového počítače? Vyjmenuj hlavní podsměry.
## back
- Zkoumá strukturu a chování počítače.
- Řeší specifikaci funkčních modulů, jako procesor, paměť, instrukční sada.
- Hlavní podsměry:
  - ISA (Instruction Set Architecture) — architektura souboru instrukcí
  - Mikroarchitektura — konkrétní sestavení a složení procesoru
  - Systémový design — řeší další hardware komponenty

# SP-29-2
## front
Jaké základní části tvoří každý číslicový počítač?
## back
- Datová část procesoru (ALU, registry)
- Řadič (řídící jednotka procesoru)
- Paměťový subsystém
- Vstupní zařízení
- Výstupní zařízení

# SP-29-3
## front
Porovnej Von Neumannovu a Harvardskou architekturu. {schematické obrázky jejich rozdělení paměťového subsystému}
## back
- Von Neumannova architektura:
  - Data a instrukce jsou uloženy společně v jedné paměti.
  - Nejsou explicitně od sebe odděleny.
- Harvardská architektura:
  - Data a instrukce jsou uloženy odděleně, mají vlastní paměťový prostor.

# SP-29-4
## front
Popiš typický instrukční cyklus počítače.
## back
1. IF — Instruction Fetch (načtení instrukce)
2. ID — Instruction Decode (dekódování instrukce)
3. OF — Operand Fetch (načtení operandů)
4. IE — Instruction Execution (provedení instrukce)
5. WB — Write Back (uložení výsledku)
6. (volitelně) Obsluha přerušení

# SP-29-5
## front
Co obsahuje instrukce procesoru?
## back
- Informaci o tom, co se má provést (operační kód)
- S jakými daty (operandy se má pracovat)
- Kam uložit výsledek
- Kam pokračovat v provádění (řízení programového toku)

# SP-29-6
## front
Vyjmenuj základní aspekty, které musí definovat ISA (Instruction Set Architecture).
## back
- Typy a formáty instrukcí, instrukční soubor
- Datové typy, kódování a reprezentace, způsob ukládání dat v paměti
- Módy adresování paměti a přístup k datové a instrukční paměti
- Řešení mimořádných stavů

# SP-29-7
## front
Jaké výhody poskytuje ISA (Instruction Set Architecture)?
## back
- Abstrakce (možnost různě implementovat stejnou architekturu instrukcí)
- Definuje rozhraní mezi SW a HW
- Standardizuje instrukce a bitové vzory strojového jazyka

# SP-29-8
## front
Charakterizuj střadačově (akumulátorově) orientovanou ISA. Jaké má výhody a nevýhody?
## back
- Akumulátor je speciální registr pro mezivýpočty, používá se jako implicitní zdroj i cíl.
- Instrukce mají typicky jeden operand.
- Výhody:
  - Jednoduchý HW
  - Minimální vnitřní stav → rychlé přepínání kontextu
  - Krátké instrukce
  - Jednoduché dekódování instrukcí
- Nevýhody:
  - Častá komunikace s pamětí
  - Omezený paralelismus mezi instrukcemi

# SP-29-9
## front
Charakterizuj zásobníkově orientovanou ISA. Jaké má výhody a nevýhody?
## back
- Pracovní registry uspořádány do zásobníku, přístup k vrcholu.
- Instrukce typicky nemají operandy, používají implicitně hodnoty ze zásobníku.
- Výhody:
  - Jednoduchá a efektivní adresace operandů
  - Krátké instrukce i programy
  - Jednoduché dekódování instrukcí
  - Snadná implementace základního překladače
- Nevýhody:
  - Není možný náhodný přístup k lokálním datům
  - Omezený paralelismus (zásobník je sekvenční)
  - Těžká minimalizace přístupů do paměti

# SP-29-10
## front
Charakterizuj registrově orientovanou ISA pro všeobecné použití (GPR). Jaké jsou hlavní výhody a nevýhody?
## back
- General Purpose Registers (GPR), instrukce typicky se 2–3 operandy.
- Výhody:
  - Registry (a cache) jsou rychlejší než paměť
  - K registrům je možný náhodný přístup
  - Registry mohou obsahovat mezivýsledky a lokální proměnné
  - Méně častý přístup do paměti
- Nevýhody:
  - Složitější překladač (optimalizace registrů)
  - Delší čas přepnutí kontextu

# SP-29-11
## front
Vyjmenuj základní úrovně paměťového subsystému počítače.
## back
- Cache (skrytá paměť) — rychlá, drahá, blízko procesoru
- Hlavní paměť — pomalejší, levnější, větší
- Vnější paměť (např. HDD, SSD) — pomalá, velká
- Záložní paměť (CD, DVD, flash, magnetické pásky)

# SP-29-12
## front
Jaké jsou základní typy pamětí podle přístupového mechanismu?
## back
- RAM (Random Access Memory) — přístup pomocí adresy
- CAM (Content Addressable Memory) — přístup pomocí klíče (obsahu)

# SP-29-13
## front
Popiš paměťovou hierarchii moderního počítače. {schéma hierarchie}
## back
- Registry (nejrychlejší, nejmenší)
- L1 cache (SRAM)
- L2 cache (SRAM)
- L3 cache (SRAM)
- Hlavní paměť (DRAM)
- HDD, SSD (sekundární úložiště)
- Mass storage (optická média, pásky — archivace)
- Remote storage (cloud, vzdálená úložiště)

# SP-29-14
## front
Definuj pojem cache. Jaké typy lokalit využívá?
## back
- Cache je rychlá paměť, umístěná blízko procesoru, uchovává kopie často používaných dat z hlavní paměti.
- Lokalita:
  - Časová lokalita — data, k nimž byl právě přístup, budou pravděpodobně potřeba znovu brzy.
  - Prostorová lokalita — po přístupu k nějakým datům budou pravděpodobně použita i sousední data.

# SP-29-15
## front
Vyjmenuj hlavní výhody cache paměti. {schématický obrázek cache mezi CPU a RAM}
## back
- Výrazně zrychluje přístup k často používaným datům (nižší latence než DRAM)
- Snižuje zátěž hlavní paměti
- Využívá principy časové a prostorové locality

# SP-29-16
## front
Proč je paměťová hierarchie v počítači víceúrovňová?
## back
- Různé úrovně paměti umožňují kombinovat výhody rychlosti (cache, registry) a kapacity/ceny (DRAM, HDD).
- Vyšší úrovně jsou menší a rychlejší, nižší úrovně větší a pomalejší.
- Zajišťuje efektivní kompromis mezi rychlostí, kapacitou a cenou.

# SP-29-17
## front
K čemu slouží registry v paměťové hierarchii?
## back
- Jsou nejrychlejší pamětí v počítači, přímo dostupné procesoru.
- Uchovávají data a mezivýsledky během výpočtů.
- Používají se pro rychlé operace a předávání operandů mezi instrukcemi.

# SP-29-18
## front
Co rozumíme pod pojmem "skrytá paměť" v kontextu architektury počítače?
## back
- Skrytá paměť je synonymum pro cache paměť.
- Jedná se o rychlou a malou paměťovou oblast mezi procesorem a hlavní pamětí, která zvyšuje výkon díky uchovávání často používaných dat.

# SP-29-19
## front
Jak cache paměť zlepšuje výkon počítače?
## back
- Ukládá často používaná data a instrukce blíž procesoru, čímž redukuje čekací dobu.
- Většina přístupů k datům pak nevyžaduje pomalé operace hlavní paměti ("cache hit").
- Tím celkově zrychluje zpracování programů.
